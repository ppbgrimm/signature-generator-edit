คู่มือการตั้งค่า (Installation Guide)

TH|EN

เลือกแท็บ Desktop ด้านบนแล้วกด Copy to Clipboard ก่อนเริ่มตั้งค่า

New Outlook for Windows (เวอร์ชันใหม่)

  1. คลิก Settings ⚙️ > Accounts > Signatures
  2. หากมีหลายบัญชี ให้เลือกบัญชีอีเมลที่ต้องการใช้ลายเซ็น
  3. คลิก Add signature แล้วตั้งชื่อ เช่น "B.Grimm"
  4. คลิกในกล่องแก้ไขลายเซ็น แล้ววางโดยกดปุ่ม Ctrl + V
  5. ด้านล่างกล่อง เลือกให้ใช้ลายเซ็นนี้กับข้อความใหม่ (new messages) และการตอบกลับ/ส่งต่อ (replies and forwards) แล้วกด Save

Classic Outlook for Windows (เวอร์ชันเดิม)

  1. ไปที่ File > Options > Mail > Signatures... (หรือเปิดอีเมลใหม่ แล้วเลือก Signature > Signatures... ในแท็บ Message)
  2. ในช่อง E-mail account เลือกบัญชีอีเมลของคุณ
  3. ใต้ Select signature to edit คลิก New > ตั้งชื่อลายเซ็น > OK
  4. คลิกในกล่อง Edit signature แล้ววางโดยกดปุ่ม Ctrl + V
  5. ใต้ Choose default signature เลือกชื่อลายเซ็นในช่อง New messages และ Replies/forwards แล้วกด OK

Outlook for Mac

  1. ที่เมนู Outlook เลือก Settings > ใต้ Mail เลือก Signatures (Legacy Outlook for Mac: ใต้ Email)
  2. คลิก + เพื่อเพิ่มลายเซ็นใหม่ ตั้งชื่อ แล้ววางในช่องแก้ไขโดยกดปุ่ม ⌘ + V
  3. ใต้ Set default signature เลือกบัญชี แล้วตั้งค่า For new messages และ For replies or forwards เป็นลายเซ็นนี้ จากนั้นปิดหน้าต่าง Signatures

หมายเหตุ: สำหรับบัญชี Microsoft 365 ลายเซ็นของ New Outlook จะถูกเก็บไว้ในเมลบ็อกซ์ (คลาวด์) และใช้ร่วมกับ Outlook on the web ส่วน Classic Outlook (เวอร์ชัน 2303 ขึ้นไป) จะซิงก์ลายเซ็นที่ตั้งเป็นค่าเริ่มต้นไปด้วย ยกเว้นองค์กรปิดฟีเจอร์นี้ไว้ ทั้งนี้ Outlook for Mac และแอปมือถือต้องตั้งค่าแยกในแต่ละเครื่อง

Select the Desktop tab above and click Copy to Clipboard before you start.

New Outlook for Windows

  1. Click Settings ⚙️ > Accounts > Signatures
  2. If you have more than one account, select the account to apply the signature to
  3. Click Add signature and give it a name (e.g. "B.Grimm")
  4. Click inside the editing box and paste by pressing Ctrl + V
  5. At the bottom, choose to apply it to new messages and to replies and forwards, then click Save

Classic Outlook for Windows

  1. Go to File > Options > Mail > Signatures... (or open a new email and select Signature > Signatures... on the Message tab)
  2. In E-mail account, choose your email account
  3. Under Select signature to edit, click New > type a name > OK
  4. Click inside Edit signature and paste by pressing Ctrl + V
  5. Under Choose default signature, select your signature for New messages and Replies/forwards, then click OK

Outlook for Mac

  1. On the Outlook menu, select Settings > under Mail, select Signatures (Legacy Outlook for Mac: under Email)
  2. Click + to add a new signature, name it, then paste into the editor by pressing ⌘ + V
  3. Under Set default signature, select your account and set For new messages and For replies or forwards, then close the Signatures window

Note: For Microsoft 365 accounts, new Outlook stores signatures in your mailbox (cloud) and shares them with Outlook on the web. Classic Outlook (version 2303 or later) also roams signatures set as defaults, unless your organization has turned this off. Outlook for Mac and the mobile app must be set up separately on each device.

  2. Go to Outlook on the web (outlook.office.com) > click Settings ⚙️ (top right)
  3. Select Accounts > Signatures
  4. Click Add signature and give it a name
  5. Click inside the editing box and paste by pressing Ctrl + V
  6. At the bottom, choose to apply it to new messages and to replies and forwards
  7. Click Save

Note: Signatures created in Outlook on the web are stored in the cloud and also appear in new Outlook for Windows (the steps are the same), so you don't need to create them twice.

หมายเหตุ: ลายเซ็นใช้ได้ไม่เกิน 10,000 ตัวอักษร (รวมรูปภาพ)

  1. Select the Desktop tab above and click Copy to Clipboard
  2. Open Gmail on a computer > click Settings ⚙️ (top right) > See all settings
  3. On the General tab, scroll to Signature, click + Create new and name it
  4. Click inside the text box and paste by pressing Ctrl + V
  5. Under Signature defaults, choose your signature for new emails (For new emails use) and replies/forwards (On reply/forward use)
  6. Scroll to the bottom of the page and click Save Changes

Note: Signatures can be up to 10,000 characters (images count toward the limit).

หมายเหตุ: แอปมือถือรองรับการจัดรูปแบบลายเซ็นได้จำกัด (เช่น รูปภาพหรือตารางอาจแสดงไม่ถูกต้อง) จึงควรใช้รูปแบบ Mobile และลายเซ็นในแอปมือถือต้องตั้งค่าแยกจากคอมพิวเตอร์

  1. Switch to the Mobile tab above > Copy to Clipboard
  2. In the Outlook app (iOS/Android), tap your account/profile icon (top left) > tap Settings ⚙️
  3. Under Mail, tap Signature
  4. To use a different signature for each account, turn on Per Account Signature and pick the account
  5. Delete the old text, long-press to Paste the new signature, then go back (it saves automatically)

Note: The mobile app has limited signature formatting support (e.g. images or tables may not display correctly), so use the Mobile template. Mobile signatures are set up separately from your computer.
